# Visual asset provenance and reuse

The catalog records the source and limitations of each asset. Project contributors offer their rights in these bundled project assets under the root MIT license, to the extent they hold such rights. This does not assert exclusive copyright in AI-generated pixels or grant rights in third-party marks or depicted content.

- `mixed-task-scenes-reference.png`: historical GPT Image concept supplied during project development. It contains a known misleading KV-gap depiction; use as a documented before-example, not as scientific evidence.
- `mixed-task-scenes-unified.png`: GPT Image revision; its exact recorded prompt is included. It illustrates a specific KV-retention policy, not a universal property of all Agent systems.
- `mixed-task-elements/`: independently addressable crops/views of generated pixels. SVG wrappers are not native vector reconstructions. The truncated Agent-model view is reference-only.
- `agent-components/`: generated Agent runtime and tool-workspace identity examples, with prompts and provenance. These are optional raster assets, not prescribed component layouts or actual product architectures.
- `gpu-flat-native.drawio`: project-authored editable device-identity schematic; not a product-specific circuit diagram. The original drawing transcript is unavailable.

These assets are not official product images, measured results, or third-party paper figures. Check the catalog's reuse/status fields and inspect an asset at the target scale before inserting it into a manuscript.
