# Repository maintenance

- Maintain this repository as the single local source for `systems-figure-studio`. Update the existing checkout in place; do not create redundant clones or copied skill installations.
- Local browsing uses the root `guide.html`. Build publication bundles only on demand in a temporary directory outside the checkout, then remove the temporary bundle after use. Do not leave a nested copy containing another `SKILL.md`.
- Preserve user changes and historical release archives. Commit, push and publish only when explicitly authorized.
