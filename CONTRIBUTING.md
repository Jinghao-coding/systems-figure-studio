# Contributing

Keep a change focused on a real figure-design need. Update the relevant topic rather than adding a second recipe catalog. Follow [the term template](templates/term-card.md), preserve stable IDs, and distinguish source evidence, original construction proposals and generated-image reviews.

For a new image, include its actual prompt when available, source/reference roles, provenance, license scope and known defects. Do not fabricate a prompt for an old asset whose generation record is missing. Never contribute private manuscripts or third-party paper images without permission. Keep scientific quantities and measured plots traceable to actual data.

Run the three validation commands in the README. For visual changes, inspect the rendered output at its intended scale; include the relevant preview and explain actual checks. Avoid claiming universal typography, publication compliance or backend support without evidence.

When modifying preserved Agent recipe bodies deliberately, update the preservation record's current-body hash and explain the change; keep the historical source hash. Index/guide generation is deterministic and should not introduce unrelated changes. No default backup copies are needed; use Git history.
