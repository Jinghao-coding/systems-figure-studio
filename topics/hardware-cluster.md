## 集群

**词条 ID：** `cluster`  
**词汇与别名：** cluster、集群、异构集群、多租户、资源池、virtual cluster  
**含义：** 多个计算节点、设备与资源归属构成的执行环境。

### 节点阵列＋局部展开

先重复机器单元，在每台内部放少量可辨的设备封装；只将焦点机器拉出剖面，保留节点—设备两层归属。

### 拓扑骨架＋节点截面

以少量实际链路构成主骨架，端点使用含计算阵列和存储条的紧凑节点截面；不画机房摄影式细节。

### 资源底板＋任务覆盖层

在同一资源底板上展示已有占用，再把一个带稳定身份的候选任务覆盖层放入可行区域；格子只承担容量语义。

**参考与取舍：** [R26](../references/sourcebook.md#r26)、[S03](../references/sourcebook.md#s03)。节点与设备的包含关系来自 R26，资源时间份额参照 S03；拓扑轮廓和资源底板是泛化构造。

**必要边界：** 节点归属、拓扑和资源单位分开；未给出的设备数量、带宽仅作示意。

## 计算节点与服务器

**词条 ID：** `node`  
**词汇与别名：** node、worker、server、rack、NUMA、机架  
**含义：** 一台计算节点中的处理器、存储和连接，或其简化身份。

### 模块化剖面

将 CPU/GPU 计算区、侧置存储条、主存平面画在共享边界内，外部只保留输入/网络端口；需要内部结构时采用局部剖面；只需定位节点时可保留同风格服务器小图标。

### 展开式节点

主体保留窄侧面，内部设备向一侧有序展开，细引出线指向原安装位置；用展开关系表达组成。

**必要边界：** 这两种为结构改编，不是某型号服务器的真实布局。

## GPU 与加速卡

**词条 ID：** `accelerator`  
**词汇与别名：** GPU、NPU、TPU、FPGA、ASIC、加速卡、NVIDIA、AMD、昇腾、寒武纪、SM、Tensor Core  
**含义：** GPU 或专用加速器；区分物理板卡、芯片与执行组织。

### 阵列与局部单元（芯片结构示意）

重复计算单元间有细互连；侧置缓冲条，拉出一个单元显示 ALU 与寄存器，用特殊运算轮廓保留辨识度。

### 专用加速器的分配网与归约树

仅用于具备该结构的专用加速器：在紧凑封装中排列分配网、运算点阵与归约树，高亮一条数据路径。GPU 板卡或通用设备身份不套用这一内部架构。

### 计算面与存储面的分解视图

计算平面与侧置存储分区错位展开，一束明确的数据路径连接两者；仅做通用示意，不声称实际封装结构。

### 简化板卡或芯片身份

使用薄型板卡或芯片轮廓，保留中央计算体和少量存储部件；省去散热器、螺丝等无关细节。与节点或网络符号保持统一线条和视角，可直接作为设备身份，不强制展开内部阵列。

### 薄板卡与局部封装

用略长的PCB轮廓、薄侧面和局部安装挡片形成设备外形；中央计算封装与两侧显存分开，边缘可露出短金手指。主芯片有明确身份或简洁内部计算面，部件之间保留间距。色彩以板卡和封装的浅明暗变化为主，不用高光质感代替形体。作为小图标时省略针脚和安装细节，保持轮廓及中央计算体；作为大图元时增加有辨识作用的局部而非放大空白矩形。示意部件数量不表示真实产品规格。

**参考与取舍：** [R17](../references/sourcebook.md#r17)、[R18](../references/sourcebook.md#r18)。PE 与局部剖面参考 R17；交叉互连和归约树只适用于 R18 一类专用架构，不作为通用 GPU 实物图。

**必要边界：** 特定论文微架构不等于所有 GPU；厂商能力与布局无依据时不画。

## 线程、算子与计算单元

**词条 ID：** `compute`  
**词汇与别名：** warp、thread block、thread、kernel、SIMT、计算单元、stream  
**含义：** 计算单元、线程组或算子执行的局部结构。

### 执行阵列中的活动前沿

计算点阵中只高亮一条活动行或一组单元，输入切片沿侧边进入，局部输出从另一侧汇出。

### 算子内部的数据收敛

用两束输入、乘加运算点、局部缓冲和输出向量展示 kernel 内部主路径；省略大多数线程。

## 网络与互连

**词条 ID：** `network`  
**词汇与别名：** PCIe、NVLink、NVSwitch、InfiniBand、RDMA、网络拓扑、带宽、link  
**含义：** 通信端点、链路、交换或数据重排关系。

### 多级交叉交换网

细节点与交叉连线构成多级拓扑，外围端口对齐，少量选中路径高亮；不为对称而添加不存在的链路。

### 数据重排的二部连线

左右两组端点各附短数据向量；弧线表示数据从源分区到目标分区的置换，端点身份保持。

## 异构设备画像

**词条 ID：** `device-profile`  
**词汇与别名：** heterogeneous device、设备画像、算力、显存、带宽、CPU、GPU、NPU、TPU、FPGA、ASIC  
**含义：** 同一任务所面对的设备类型与性能条件。

### 设备轮廓与侧置属性条

将不同设备放在同一基线上，采用相容的芯片或板卡小轮廓。每个设备旁只放与判断有关的属性带，例如显存容量、计算能力与链路；焦点属性展开，其余用短标签。属性带分别标单位，不能把长度相同解释为能力相同。

### 共享任务与设备条件扇出

将一个带稳定 ID 的任务小图置于左侧，右侧扇出不同设备条件。任务形体只画一次，每条候选路径附自己的设备标签与预测记录；用弱化的路径保留备选，不把图画成多份任务已同时执行。

**参考与取舍：** [S01](../references/sourcebook.md#s01)、[S03](../references/sourcebook.md#s03)。借鉴硬件条件比较的语义；设备轮廓与属性布局是补充构造。

**必要边界：** 未经实测的性能只用符号或明确的示意值；不同类型加速器不共用虚构的内部版图。

## NUMA 与互连局部性

**词条 ID：** `numa-locality`  
**词汇与别名：** NUMA、PCIe、NVLink、NVSwitch、RDMA、InfiniBand、locality  
**含义：** 设备、内存与网络之间的局部性和跨域访问。

### 局部岛与跨域桥

把一个 NUMA 域的 CPU、主存和直连设备收在轻边界内，不同域并排成局部岛；跨域路径从明确端口穿过中间桥接区。优先突出当前任务访问的那条路径，设备小图标保持同一比例。

### 拓扑主图与路径抽条

主图只保留必要端点和交换层，从中抽出一条 CPU—链路—GPU 的访问路径放在下方。主图端点与抽条保持 ID 对应，用接口与跳数标签解释差别，不把低带宽画成断路。

**必要边界：** PCIe、NVLink 和网络交换的实际连接须由部署确定；示意拓扑不是具体服务器布线图。

## 空间分区、时间共享与并发

**词条 ID：** `device-sharing-modes`  
**词汇与别名：** MIG、MPS、time slicing、GPU sharing、隔离、并发  
**含义：** 比较不同共享方式的资源边界与执行组织。

### 分区剖面

在一个 GPU 轮廓内用明确边界显示硬件分区，各区分别包含必要计算与存储部分；任务入口接到所分配区域。只在确有硬件分区时使用这种切法，边界位置与比例作示意。

### 同卡多流与时间片对照

保留相同的 GPU 身份，下方分别展开多条流的执行片段，或单条交替时间片。并发图用重叠表达同时执行，轮换图用连续区间表达占用次序；用小标签说明机制，不仅换颜色。

## CPU、核心与主机处理

**词条 ID：** `cpu-processor`  
**词汇与别名：** CPU、processor、socket、core、vCPU、主机处理器、处理器封装  
**含义：** CPU 的实体身份、内部核心组织，或在异构计算中的主机侧作用。

### 处理器封装与短标签

用正视或轻微倾斜的芯片轮廓表示 CPU，保留中央计算面与少量边缘触点。旁边标 CPU 或 socket ID；与 GPU 板卡共享线宽、配色和视角，不通过夸张芯片大小推断性能。适合节点内部的小型身份组件。

### 核心组与共享缓存的局部展开

先画封装外形，仅展开一个示意核心组；少量重复核心围绕独立缓存带排列，主存放在封装外。其余核心组折叠为相同轮廓。数量和缓存拓扑无依据时标为示意，不能拿 GPU 的 SM 或专用加速器归约树替代 CPU 内部结构。

### 主机准备与设备计算双区

主机侧用 CPU 小芯片和少量预处理任务，设备侧复用 GPU 板卡与张量组件；数据通过主存／传输带进入设备。仅在真实流程中存在时展开解码、预处理、数据加载，不预设所有 GPU 数据都必须复制经过 CPU。需要表达时序则抽出 CPU 准备与 GPU 执行两条轨道。

**参考与取舍：** 原创通用构造；没有绑定特定 CPU 型号或专门论文原图。

**必要边界：** 物理 socket、核心、硬件线程和 vCPU 是不同粒度；没有绑定策略时不把每个线程永久连到某个物理核心。

**状态：** 原创／改编绘图描述可用；未生成图片。新增官方来源仅核文本，不宣称已审其图面或已获用户视觉认可。
