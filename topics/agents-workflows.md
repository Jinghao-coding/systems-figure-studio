## 工作流与 DAG

**词条 ID：** `workflow`  
**词汇与别名：** workflow、DAG、fork、join、dependency、前驱、后继、critical path、任务图  
**含义：** 任务依赖、执行映射与就绪状态。

### 紧凑fork/join骨架

用五六个稳定节点构成真实分叉汇合，节点边缘有微型状态标记；中间产物用短数据片附在依赖边。

### 逻辑图悬置于执行泳道

上层同一DAG，下层worker泳道，细映射线落到任务执行片；两层职责清楚。

### 同一工作流的连续状态

节点位置不变，只完成/ready/running状态改变；真实join等待条件写在对应汇合旁。

**参考与取舍：** [R27](../references/sourcebook.md#r27)、[AG04](../references/sourcebook.md#ag04)。借鉴所列来源的局部形体或组织关系；各候选是改编描述，不表示每种画法都直接出现在原图。

**必要边界：** 有循环的执行结构不能标DAG；ready不等于running。

## Agent 与多 Agent

**词条 ID：** `agent`  
**词汇与别名：** Agent、planner、executor、coordinator、environment、action、observation、LangGraph、AutoGen  
**含义：** 执行角色及其真实交互，可采用头像、结构或组合式表达。

### 有输入产物的行动回路

中心保留简化模型结构，动作以带参数的小调用片输出，环境观察以结果片回流，记忆只在读写时相连。

### 多角色的任务交接

各角色可用同风格头像＋短标签，或模型结构＋角色端口；任务/产物有稳定ID，委派与汇总各有方向。

**参考与取舍：** [AG01](../references/sourcebook.md#ag01)、[AG02](../references/sourcebook.md#ag02)、[AG05](../references/sourcebook.md#ag05)。借鉴所列来源的局部形体或组织关系；各候选是改编描述，不表示每种画法都直接出现在原图。

**必要边界：** 这是由已审结构重组的提案，LSTM门控不移植为Agent内部机理。

## 工具调用与产物

**词条 ID：** `tool`  
**词汇与别名：** tool call、function call、MCP、工具、API、artifact、代码、测试、文件传递  
**含义：** 带参数调用、接口执行和返回产物。

### 调用片—执行接口—结果页

输入包含工具名与少量参数，穿过窄接口，输出展开文件/执行记录小页；调用ID连贯，失败沿返回路径。

### 工具槽与已插入能力

一组有名称与输入输出类型的接口槽，只焦点槽接到真正调用片；只识别工具时可用简洁图标；解释调用行为时保留输入、执行和返回关系。

**参考与取舍：** [AG03](../references/sourcebook.md#ag03)。借鉴所列来源的局部形体或组织关系；各候选是改编描述，不表示每种画法都直接出现在原图。

**必要边界：** 工具定义、调用实例和执行结果分开；本类缺少专门已审形体原图。

## 上下文、记忆与 RAG

**词条 ID：** `context-memory`  
**词汇与别名：** context window、memory、RAG、retrieval、vector database、检索、对话历史、共享状态  
**含义：** 上下文、检索材料、长期记忆与当前有效窗口。

### 共享上下文主干与后缀

公共前缀单份画在主干，分支追加各自向量/片段；引用方向清楚。

### 检索页束进入上下文窗口

检索结果是含少量内容的页束，只有选中页进入有限长上下文带；原知识库保留，不把检索画成移动删除。

## 分支、路由与循环

**词条 ID：** `routing`  
**词汇与别名：** conditional routing、branch、loop、router、状态机、FSM、条件分支  
**含义：** 条件分支、选中路径与实际反馈。

### 候选路径与唯一选择

输入token/任务节点通过条件扇出，候选路径细显，实际选中一条突出，未选对象仍可辨。

### 带回传数据的循环

回路沿外侧绕行，输入和反馈数据形态不同；循环内部只展开一个迭代步，停止条件在出口。
