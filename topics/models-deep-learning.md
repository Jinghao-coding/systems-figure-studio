## 张量、向量与矩阵

**词条 ID：** `tensor`  
**词汇与别名：** tensor、matrix、vector、activation、feature、权重、梯度、SP、CP  
**含义：** 向量、矩阵或多维数据及其切片、通道、维度。

### 斜置的特征片组

若干带细网格的平面错位叠放，前面抽出一片。用于特征图时长宽可表示空间维、叠层可表示通道；用于其他张量时明确各轴含义。保持统一视角，让前景切片成为焦点。

### 窄向量带与分量

使用长宽明显不对称的分格带；一端附 token/字段身份，内部少量不同填充表示分量。

### 有剖面的张量体

低透视立体体块露出三轴，一张切片从对应轴抽出并放大；厚度由轮廓和轻明暗辅助，避免用厚重投影掩盖切片。

### 矩阵 tile 与遍历路径

在二维平面上只突出一个 tile，旁边展示该 tile 的输入/输出条；虚线标未物化的中间空间。

**参考与取舍：** [R02](../references/sourcebook.md#r02)、[R06](../references/sourcebook.md#r06)、[R19](../references/sourcebook.md#r19)。借鉴所列来源的局部形体或组织关系；各候选是改编描述，不表示每种画法都直接出现在原图。

**必要边界：** 每一轴或重复方向都要有明确含义；示意格数不是真实 shape。

## 神经网络

**词条 ID：** `network-model`  
**词汇与别名：** 深度学习、神经网络、CNN、RNN、Transformer、encoder、decoder、大模型  
**含义：** 网络层次、重复结构与局部计算。

### 一层展开的重复模型体

多层沿一个方向排列，只有一层展示局部网络与残差，其余层只露结构轮廓；保持贯穿输入路径。

### 圆节点网络骨架

有限的神经元圆点按层分组，关键连接完整，非关键边弱化；末端接真实向量或记录。

### 压缩—展开的编码解码体

两个对向梯形组成收窄再展开的轮廓，跨层跳接沿上方绕行，瓶颈向量单独可见。 这种轮廓适合实际具有收缩—扩展层次的结构；仅表示 Encoder/Decoder 名称时不强制画成降维与升维。

**参考与取舍：** [R04](../references/sourcebook.md#r04)、[R07](../references/sourcebook.md#r07)、[R11](../references/sourcebook.md#r11)。借鉴所列来源的局部形体或组织关系；各候选是改编描述，不表示每种画法都直接出现在原图。

**必要边界：** 沙漏只适用于对应结构；不把所有 LLM 画成编码解码沙漏。

## 注意力机制

**词条 ID：** `attention`  
**词汇与别名：** attention、self-attention、cross-attention、QKV、causal mask、PagedAttention  
**含义：** 注意力中的输入、得分、加权与多头结构。

### 多路 value 的加权汇聚

相同长度向量与标量权重在各自圆形乘点汇合，再共同进入加法汇聚；输入身份不变。

### Q/K/V 切片与得分平面

Q 竖向、K 横向、V 侧置，乘积关联到得分平面；局部格或 tile 高亮，输出向量独立。

### 多头的平行小通道

头部通道以小尺寸重复，内部只展开一个头；末端明确 concat 和投影，不能直接画所有通道相加。

**参考与取舍：** [R08](../references/sourcebook.md#r08)、[R19](../references/sourcebook.md#r19)。借鉴所列来源的局部形体或组织关系；各候选是改编描述，不表示每种画法都直接出现在原图。

**必要边界：** 权重、mask 与稀疏路由不同；只显示机制需要的矩阵细节。

## GNN 与图表示

**词条 ID：** `gnn`  
**词汇与别名：** GNN、GCN、GAT、GraphSAGE、图神经网络、message passing、graph embedding  
**含义：** 图对象、邻域传播与节点／图表示。

### 图通过层叠平面

同一小图在输入/输出端出现，中间穿过两三张倾斜平面；不同层之间保留稳定节点身份。

### 焦点邻域的消息扇入

只突出中心节点、一跳邻居和沿边传入的小消息向量；一侧接聚合后的向量条。

### 重复时刻的同一图

多个时间薄层保留相同节点位置，用跨层连线表示同一节点的时间关系；空间边和时间边可辨。

**参考与取舍：** [R03](../references/sourcebook.md#r03)、[R12](../references/sourcebook.md#r12)、[R20](../references/sourcebook.md#r20)。图、邻域与时间展开分别取局部表达，只有模型实际需要时组合。

**必要边界：** 不能把消息图自动改成全连接，也不能将时间层误标网络层。

## MoE 与专家

**词条 ID：** `moe`  
**词汇与别名：** MoE、expert、router、gating、Top-k、dispatch、combine、EP、共享专家  
**含义：** 路由、专家选择、容量和合并。

### 概率小柱＋专家阵列

token 向量先出现路由概率小柱，随后只有被选专家的路径实显；保留未选专家，末端执行明确 combine。

### 专家槽位与 token 重排

输入 token 窄条在源端成组，目标端按专家分开；相同 token 色/ID 沿连线保留，空位和溢出可辨。

### 按设备分布的专家切片

专家本体各自包含微型网络或参数切片，置于明确设备边界，跨设备连线只连接实际选择。

## 多模态模型

**词条 ID：** `multimodal`  
**词汇与别名：** VLM、multimodal、视觉语言模型、audio、video、跨模态、Gemini、Claude  
**含义：** 不同模态的数据表示与融合位置。

### 不同模态形体汇成向量

图像使用patch片，文本使用token带，音频使用短波形/时频片，各自映射到统一向量后融合。

### 具象输入—分支编码—融合表示

按模态或特征类型排成开放的平行支路：每路先展示可辨认的输入（序列带、关系图、特征记录），再接对应编码对象和窄向量。支路保留同一色族，到实际融合处汇合；融合之后再连接输出模型或预测结果。各支路可有不同内部结构和长度，不为对称强行等大。参考 figures4papers 的 ImmunoStruct 示意图，具体颜色与阅读范围见 [图例记录](../references/figures4papers-ideas.md)。仅借形体与组织，融合运算、支路数量和输入语义由当前论文决定。

### 条件支路进入生成主体

编码后的条件平面或向量从侧面进入真实cross-attention位置，主干仍保留生成/去噪结构。

**参考与取舍：** [R13](../references/sourcebook.md#r13)、[R14](../references/sourcebook.md#r14)、[R11](../references/sourcebook.md#r11)。借鉴所列来源的局部形体或组织关系；各候选是改编描述，不表示每种画法都直接出现在原图。

**必要边界：** 音频形体为补充；模态输入不应全部成为写着Image/Text的相同矩形。

## 量化与反量化

**词条 ID：** `quantization`  
**词汇与别名：** quantization、dequantization、INT8、INT4、FP8、scale、zero point、PTQ、QAT  
**含义：** 数值精度、尺度和表示转换。

### 值轴到离散台阶

左侧短值轴上放少量浮点样本点，右侧用离散台阶表示量化级；对应点通过短线落到级别上，尺度参数放在轴旁。仅解释离散化时不用绘制整套训练网络。

### 张量平面与尺度边条

保持输入与量化后张量相同的形状，以元素位宽标签区分表示，尺度作为独立边条沿通道或组排列。反量化路径从数值表示与尺度共同进入，不通过缩小矩阵面积暗示减少元素数量。

### 异常通道的前后对照

保持激活与权重两列，用简化幅度轮廓对照变换前后；只展开异常通道，变换路径同时指向两侧。取自平滑缩放的机制启发，通用量化无需强行加这一步。

**参考与取舍：** [S08](../references/sourcebook.md#s08)。保留尺度、通道与分级关系；不继承原图的红绿评价词和密集数值。

**必要边界：** 量化不等于剪枝；低精度并不保证所有硬件都加速；示意幅度不是实验结果。

**状态：** 绘图描述可用；改编示例图未生成。具体构图、数量与外观按本次研究内容核对。

## 剪枝与稀疏表示

**词条 ID：** `sparsity`  
**词汇与别名：** pruning、sparsity、structured、unstructured、N:M、mask  
**含义：** 哪些权重或通道保留，以及稀疏模式怎样被表示。

### 稀疏点阵与掩码

同尺度并排原权重与稀疏点阵，保留元素坐标；删去位置留空，掩码独立叠在旁侧。强调少量保留路径，不用随机装饰性孔洞表示经过选择的稀疏结构。

### 整组通道抽离

将网络画成并列通道薄带，待移除的一组先用浅描边标明，下一视图按真实重排压紧剩余通道。共享输入输出位置方便比较，结构化删除与仅置零分别描述。

**参考与取舍：** 尚无专门原图。原创或通用构造候选；没有已绑定的专门原图。

**必要边界：** 非结构化稀疏不能直接画成更窄的稠密矩阵；没有内核支持不承诺按比例加速。

**状态：** 绘图描述可用；改编示例图未生成。具体构图、数量与外观按本次研究内容核对。

## 教师—学生蒸馏

**词条 ID：** `distillation`  
**词汇与别名：** knowledge distillation、teacher、student、soft targets、temperature  
**含义：** 教师提供的监督与学生训练路径。

### 双模型与分布对齐

教师与学生使用同一视觉家族的模型轮廓，输入从公共位置分流；两侧输出以对齐的概率条或特征片表示，在比较节点汇合。梯度只返回实际更新的分支，教师旁可用小锁标冻结。

两条网络骨架平行排列，使用短横线配对被监督层；层数不同保留真实匹配或投影，不强行一一对应。只展开一对特征，其他配对降为细线。

**必要边界：** 教师更大不是定义；教师是否冻结、是否在线计算以及监督形式按方法确定。

## MHA、GQA 与 MQA

**词条 ID：** `attention-head-sharing`  
**词汇与别名：** MHA、GQA、MQA、query head、KV head、head sharing  
**含义：** Query 头与 Key/Value 头之间的分组关系。

### 扇出连接与共享 KV 对

上方若干窄 Q 带按组排列，下方是成对的 K/V 带；一组 Q 指向同一 K/V 对，组间用留白隔开。MHA、GQA、MQA 采用同一布局基准，仅改变合法映射。

### 头维度切片与缓存剖面

将 Q 和 KV 张量并列，明确 head 轴；抽出一个 KV 头的缓存片，连接对应的多个 Q 头。只用少量示意头，不把头数直接等同 GPU 数量。

**参考与取舍：** 尚无专门原图。原创或通用构造候选；没有已绑定的专门原图。

**必要边界：** 说明共享发生在 KV 头；不因共享删除 token 轴或暗示注意力已计算完。

**词条 ID：** `feature-interaction`  
**词汇与别名：** DLRM、DeepFM、DCN、cross network、feature interaction、稠密特征、稀疏特征  
**含义：** 稀疏特征、稠密特征和交互计算的组合。

### 双路输入与交互汇合

类别 ID 通过表行抽取得到多个嵌入向量，数值特征沿独立窄路径进入小网络；在明确的拼接或交互节点汇合，再进入输出部分。两路保留不同数据形体，不堆品牌模型名称。

### 交互网格与重点配对

特征向量沿矩阵两侧排列，交互位置用稀疏网格表示，选中一对向量拉出运算细节。低阶交互和后续高阶网络分开，避免把所有模型都画成任意全连接。
