# Stage-appropriate validation

## Before drawing

Show the actual complete prompt (or native composition brief) before tool execution, with key object constructions and the selected palette. Distinguish disclosure from approval; wait only when the user requests approval or facts remain unresolved.

## Every generated image

- For generated component assets, inspect silhouette, transparency, target-size recognizability and style compatibility; verify actual reuse in the final figure and declare any raster editability limits.
- Inspect the actual image, not only its prompt. Compare it with the design shown to the user: check whether the promised silhouettes, focal relationship, local expansions and color roles actually appeared. Report missing visual choices as defects, not as successful recipe use.
- Objects, boundaries, multiplicities and relationships match the source material.
- Every critical arrow has the right source, target, direction and meaning.
- Comparisons preserve input identity; selection and arithmetic agree.
- Lifecycle counts, reservations, release and async order are coherent.
- No invented implementation queues, online training, brands or hardware mappings.
- Labels are legible and correct; logo approximations are identified as placeholders.
- Overview scope stays distinct from mechanism details.
- Selected component constructions are visible in the result: silhouettes, parts and organization suit the object; a structural-redesign request is not satisfied by recoloring or relabeling boxes.
- Visual quality is checked separately: silhouette and proportions identify the object at target size; neither a filled recipe checklist nor added micro-detail proves a good drawing. Revisions for stiffness address composition and component form, not only effects.
- Miniature objects identify the right entity or explain relevant structure; regions fit their contents without crowding.
- Component variants preserve paper facts and object granularity; layers, ranks, instances, roles and devices are not conflated.
- Icons/logos attach to the right owner, share a coherent style and leave connector endpoints clear.
- Intended label language matches the destination document; Chinese glyphs, English spelling, mixed-language terms and mathematical symbols are correct. Recipe IDs and planning metadata do not leak into the figure.
- Redraws retain source semantics; terminology, supported adaptations and figure roles agree with the destination chapter/section.
- Dissertation-wide figures preserve recurring concepts and symbols without inventing dependencies among chapters.
- Inherited source-review records, textual candidates and newly inspected images have separate statuses.
- Data/control/feedback are distinguishable; local guides and state borders are clear.
- Perform the [rendered aesthetic review](visual-quality.md#aesthetic-review) after new drawings or color revisions; record concrete visual findings and reinspect actual corrections.
- Check color hierarchy in the actual composition: contextual fills, object identities and focal relationships have the intended relative weight; small paths and labels remain readable. Uniformly pale or uniformly vivid treatment should be a deliberate choice, not a palette-grouping artifact.
- Neighboring figures maintain coherent identity and typography. Different figure roles may use different coordinated palettes; direct comparisons preserve color mapping. Judge reduced clutter by the actual composition rather than automatic retention of earlier colors.
- Remove editorial subtitles that repeat what the composition shows; preserve labels/conditions that materially affect interpretation.

Report scientific errors explicitly. A composition may be useful while still needing repair. Do not call it a final paper figure solely because it looks polished.

## Raster preview / manual redraw

Display the image and provide the saved prompt plus concise redraw notes. Assess readability at an approximate intended width where feasible, without inventing exact point-size measurements. Native editability, vector export, editor round-trip and LaTeX compilation are not default completion requirements.

## Requested native production

Use [editable-production](editable-production.md). Check separately addressable text/objects, intended editor reopening, export fidelity and actual-width fonts. The optional SVG/PDF script supplies limited structure/font evidence only; it is not a universal validator for draw.io, TikZ or PPTX. A passing automated structure check does not prove semantics, routing or editability.

## Requested paper integration

Compile the affected manuscript and inspect the containing page at intended width. Check caption, references, float layout and readable labels. Distinguish figure-internal whitespace from TeX spacing. Preserve results and unrelated text. If compilation or viewing is unavailable, state that limitation without claiming completed integration.
