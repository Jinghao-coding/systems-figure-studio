# 整合说明

本版用一个规则入口和一套主题正文取代旧版多套入口。52 个旧 ID 全部迁移，旧的长提示词不再照搬；术语、画法与新 icon 规则在各主题中一致。

## 实际修正

- GPU 通用身份与 SIGMA 一类专用加速器内部结构分开，新增简化板卡／芯片身份画法。
- 量化、剪枝和蒸馏成为独立词条，不再挂在 LoRA 别名下冒充覆盖。
- 模型层、参数切片、实例、rank 和设备分别表达；通用 Encoder/Decoder 名称不强制采用降维升维形状。
- MIG、MPS、时间切片区别，环／树／集体通信不作为所有场景的固定拓扑。
- 资源回收、KV 驻留、异步保存和实际就绪分别标状态，不把完成图标当释放事件。
- 原文的“而非服务器图标”“不使用仪表盘图标”等改为根据含义和局部用途选择，不一律排除图标。
- Agent 的已有主体段落保留；状态更新为用户认可整理方向，成图未生成仍单独标明。
- 来源粗粒度链接重新梳理；原图可以只作语义参考，文字提案不会自动被标为论文原有构造。
