# 可复用视觉素材库

实际素材见 [assets/visual-library](../assets/visual-library/)，机器可读记录见 [catalog.json](../assets/visual-library/catalog.json)。素材与主题画法互补：画法解释怎样表达对象，素材提供已经看过的具体造型。

## 选择与积累

范围开放，按任务需要积累模型、数据、张量、CPU/GPU、服务器、互连、存储、Agent角色、工具、运行时、队列和其他对象；不要求每类预建素材，也不把某次认可变为全部图的固定风格。仓库自带素材可作为候选或造型参考；根据语义、风格、尺度和构图选择复用、改编、生图生成局部或整图，也可使用原生图元。即使已有同类素材，也可以生成更合适的新造型，不要求先遍历或用完素材库。实际检查后按需登记。记录来源、认可范围、可编辑程度、保留与舍弃内容及适用尺度，不只保存名称和文字配方。

用户认可的视觉参考与可直接使用的干净素材分开记录。未经清理的整图可以作参考，但不能标为可直接复用的独立元素。当前 mixed-task-scenes-reference.png 是项目历史造型参考：有内容的样本页束、展开模型层与节点网络、Agent角色和具体工具具有辨识度；不保留原图把工具等待画成KV缺口的错误。实际图像来源记录为 2026-10-02 的 GPT Image 概念图及开发过程中的参考输入，非官方产品图。

## 组合前检查

- 独立元素保留完整轮廓，不带旧标签、文字残片、半截箭头或旁边对象。紧缩裁切不能以切掉模型边缘或网络节点为代价；需要时重新提取或生成。
- 整图已有独立标签时，素材中不再保留同一标签。文字应只有一份。
- 同一对象从左至右的形体、颜色与语义一致：模型和权重对应，请求词元和KV对应，时间等待不能变成状态空间中的空洞。
- 看实际导出和论文页宽缩小效果，不能用裁切坐标或Prompt替代验收。

## 交付形式

按图的用途选择GPT Image整图、图片元素与原生图元混合、或完整原生矢量图。论文说明图可以直接使用检查通过的GPT Image成图，不默认要求重建为draw.io；精确数据、频繁修改的关系或用户明确要求可编辑时选择相应原生源。混合图中的图片内部仍是像素，文字、箭头和布局可以独立编辑。保留已认可的视觉细节，不为矢量化便利简化成同形方框。

## 多元素素材页拆分

一次生成多个对象时，入库前按对象拆成独立文件，每项记录来源、裁切范围、用途和可编辑程度；整张素材页只作为来源与风格参考。用户要求忠实拆分或保留原形象时，保留实际像素；若任务允许重新设计，也可生成独立新素材，并说明它不是原图裁切件。将不能分开而不损坏轮廓的组合（例如重叠的终端与地球）作为一个组合素材；不要补造被遮挡部分。重复对象可复用完整版本。原图已有截断的对象标为仅供参考，不进入正式图。

当前可复用素材及预览：[混合任务独立素材](../assets/visual-library/mixed-task-elements/index.html)。SVG 是对原 PNG 的独立视窗封装，内部仍是像素，不能宣称全矢量；图中的文字、箭头、状态和布局另用原生图元维护。

## 按当前图选择复用、改编或生成

仓库素材提供可选示例，不固定人物、模型、Agent或环境的形象。根据当前图的解释目标与整体风格选择直接复用、调整已有素材、通过生图生成新元素或绘制原生图元；生成不以“没有现成素材”为前提。需要延续图组风格或用户明确要求保留形象时，再检查相应已有图与素材。其他图或其他项目中的认可不自动成为当前图的约束。记录实际使用的素材文件或生成来源，不以制作便利代替语义和视觉判断。

工具与执行环境例如可按实际语义选择终端、文件夹或网络入口，但不要求固定组合；标签说明其涉及的文件、进程和外部服务；不随意添加锁来暗示安全隔离，也不把图标误写成硬件节点。运行支撑可采用控制台、局部流程、上下文记录与调用接口的组合，但这些是身份概念插图，不推定某个产品的真实架构。

用于透明叠加的素材应采用真实透明背景；整图或有意设计的背景按任务处理。检查PNG的alpha和目标论文背景上的实际合成；不要仅凭忽略alpha的RGB预览判断光晕，也不要把透明棋盘格作为背景像素写入。保留完整轮廓，原生文字与箭头置于独立图层，不能让外部连线穿入身份素材后被误解为内部机制。
