## 保留已有内容

集群、节点、GPU／加速卡、内存显存、数据集存储、物理互连、NUMA、数据传输、容器与 K8s 控制执行均已有具体画法，继续复用。Agent 内容逐字保留。

## 只补发现的缺口

| 增补 | 原情况 | 现在包含 |
|---|---|---|
| Cloud 环境 | 有集群，没有专门云环境表达 | 云标题、环境边界、局部展开、多云／本地并列 |
| CPU | 在节点／设备别名中出现，缺独立构造 | CPU 封装、核心组剖面、主机处理与设备执行 |
| 存储服务 | 数据页束与搬移较多，服务外形不充分 | 本地盘／共享池、块／文件／对象服务、PVC/PV 与实际读写分层 |
| Kubernetes Logo | 只有一般 icon 允许规则 | 标识平台／边界／接口；与资源图标和整图组合 |
| 架构连接线 | 有互连和通用语义规则 | 明确端口、分层布线、骨架与焦点路径、外围反馈 |
